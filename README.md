# Strike Zone

A mobile-first wave shooter built with Three.js. Single file, no build step.

## Play
Host it with GitHub Pages: repo Settings > Pages > Deploy from branch > main / (root).
Then open `https://YOUR-USERNAME.github.io/YOUR-REPO/` on your phone.

## Controls
- Left thumb: move. Right thumb: aim. Hold FIRE and drag to aim while shooting.
- AIM zooms, SLIDE dodges, JUMP, RELOAD, gear button opens settings.
- Desktop: WASD, mouse, click to fire, right click to aim, C or Shift to slide, R to reload.

## Adding real models
Place .glb files in the repo and load them with THREE.GLTFLoader (Pages serves them from the same origin).
